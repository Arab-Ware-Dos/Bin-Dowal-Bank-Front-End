# 📍 القسم الرابع: خطة تنفيذ الفروع والصرافات والشركاء (Phase 4 Detailed Sub-Plan)

تغطي هذه الوثيقة الخطة الفرعية التفصيلية لربط موديول **الفروع والصرافات والشركاء** بالواجهات البرمجية التالية:
1. `GET /locations` (شبكة الفروع، الصرافات الآلية، الإحداثيات الجغرافية، والمدن).
2. `GET /partners` (قائمة الشركاء، الشبكات المالية، والبنوك المراسلة).

---

## 📋 الأهداف ونطاق العمل
- عرض شبكة أجهزة الصراف الآلي والفروع على الخريطة التفاعلية وفي القائمة استناداً للإحداثيات الحقيقية (`latitude`, `longitude`).
- تصفية المقار حسب النوع (`branch` / `atm`) وحسب المدينة (`city`).
- عرض الشركاء والبنوك المراسلة المعتمدة في قسم الشركاء المخصص.

---

## 🛠️ الملفات المطلوبة

### 1. الأنواع والخدمات (Types & Services)
- 📄 `types/locations.ts`: تعريف `BankLocation` و `PartnerItem`.
- 📄 `services/locations-api.ts`:
  - `fetchLocations(params?: { type?: 'branch' | 'atm'; city?: string })`
- 📄 `services/partners-api.ts`:
  - `fetchPartners(params?: { type?: 'local' | 'international' | 'corresponding_bank' })`

### 2. المكونات وصفحات الواجهة (Pages & Components)
- 📄 `app/[locale]/locations/page.tsx` (أو مكون خريطة الفروع والصرافات): ربط البيانات المرتجعة مع خريطة Google / Leaflet وحساب المسافات وتحديد الفروع وأوقات الدوام.
- 📄 `components/home/partnerships-section.tsx`: ربط الشركاء وشعارات البنوك المراسلة ديناميكياً.

---

## 🧪 خطة التحقق والاختبار
- التأكد من صحة إحداثيات الخريطة وعرض الدبابيس (Markers) بالفروع أوفلاين وأونلاين.
- التحقق من تصفية الصرافات الآلية عن الفروع بدقة.
