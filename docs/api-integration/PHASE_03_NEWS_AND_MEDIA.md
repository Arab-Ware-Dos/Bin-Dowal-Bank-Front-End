# 📰 القسم الثالث: خطة تنفيذ المركز الإعلامي والأخبار (Phase 3 Detailed Sub-Plan)

تغطي هذه الوثيقة الخطة الفرعية التفصيلية لربط موديول **الأخبار والمركز الإعلامي** بالواجهات البرمجية التالية:
1. `GET /news` (قائمة الأخبار، الأخبار المختارة، وتصفية الأخبار في الصفحة الرئيسية).
2. `GET /news/{slug}` (تفاصيل الخبر الكامل بتنسيق HTML المترجم والأخبار ذات الصلة).

---

## 📋 الأهداف ونطاق العمل
- عرض الأخبار المختارة محررياً (`is_featured=true`) في الشاشة الرئيسية وفي قسم الأخبار المخصص.
- تصفية الأخبار حسب الفئات (مثل: أخبار البنك، الفعاليات) والبحث بالنص.
- عرض تفاصيل الخبر بصوره وعنوانه والـ HTML المترجم بأمان.

---

## 🛠️ الملفات المطلوبة

### 1. الأنواع والخدمات (Types & Services)
- 📄 `types/news.ts`: تعريف `NewsItemSummary` و `NewsDetailData`.
- 📄 `services/news-service.ts`:
  - `fetchNewsList(params?: { search?: string; category?: string; is_featured?: boolean; show_in_home?: boolean })`
  - `fetchNewsArticleBySlug(slug: string)`

### 2. المكونات وصفحات الواجهة (Pages & Components)
- 📄 `components/home/news-section.tsx`: ربط الأخبار المخصصة للعرض في الصفحة الرئيسية.
- 📄 `app/[locale]/news/page.tsx`: صفحة أرشيف الأخبار الكاملة مع البحث والتصفية.
- 📄 `app/[locale]/news/[slug]/page.tsx`: صفحة تفاصيل الخبر الكامل والتحقق من تفنيط الـ HTML بأمان (`dangerouslySetInnerHTML` / Sanitizer).

---

## 🧪 خطة التحقق والاختبار
- التأكد من جلب الأخبار وتنسيقات التواريخ والصور المرفقة المرفوعة على السيرفر (`storage/news/...`).
- اختبار تصفح الخبر عبر Slug والزيادة التلقائية لعداد المشاهدات المرتجع من الـ Backend.
